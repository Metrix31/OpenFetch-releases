# OpenForge Apps

**The official release repository for OpenForge.**

OpenForge Apps is the central distribution repository for applications developed under **OpenForge** by **Metrix31 Labs**.

It provides a single place to access downloadable releases, application builds, and version information for OpenForge projects.

Designed to work with **OpenFetch**, this repository makes it easier to discover and download OpenForge applications.

---

## Purpose

OpenForge Apps serves as a central distribution point for OpenForge software.

Our goals are to:

* **Centralize Releases** - Keep downloadable application builds in one place.
* **Simplify Downloads** - Make it easy to access and download OpenForge applications.
* **Support OpenFetch** - Provide a consistent source for OpenFetch to retrieve applications.
* **Provide Version Information** - Make release versions and their associated files easy to identify.
* **Improve Accessibility** - Make OpenForge software available without unnecessary barriers.

## OpenFetch Integration

**OpenFetch** is the official download client for OpenForge Apps.

It is designed to retrieve application releases and downloadable assets from this repository.

Planned functionality includes:

* Browsing available applications.
* Viewing available versions.
* Downloading application releases.
* Selecting specific release assets.
* Tracking download progress.

For more information, visit the OpenFetch repository.

## Releases

Application releases are distributed through GitHub.

Each release may contain:

* Version information.
* Downloadable application builds.
* Release notes.
* Platform-specific files, where applicable.

Availability and file formats depend on the individual application.

Always check the corresponding release notes before installing an application.

---

## Security

OpenForge takes software distribution seriously.

* Releases should be published through official OpenForge repositories.
* Downloaded files should be treated as untrusted until their origin and integrity have been verified.
* Applications are never executed automatically by OpenFetch.
* Release information should clearly identify the application and version.

Where supported, checksums and additional integrity verification may be provided.
